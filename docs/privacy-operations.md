## 更正、删除、撤回同意和注销

1. 收件人每日检查隐私邮箱，登记请求编号、收到日期、诉求、涉及活动、负责人、进度与答复日期。申请台账存放在受控运营空间，不写入 Git、公开工单或普通分析导出。
2. 通过已登录账号或已验证联系方式做最小身份核验；不索要密码、短信验证码或无关证件/健康详情。避免仅凭公开姓名删除他人数据。
3. 确认影响范围：`participant_accounts`、`registrations`/`registration_answers`、`checkins`、`activity_pairs`、培训签到、`submissions`/`answers`、导出任务/文件，以及能关联个人的审计或安全日志。保留依法必须保存的最小记录时，登记依据、期限和用途限制。
4. 更正本场姓名时修改该场报名答案，不覆盖其他活动姓名。删除/注销由授权运维人员按具体请求准备处置清单，在隔离恢复库验证关联完整性、权限与统计后执行；先失效账号会话，再清除或真正匿名化业务关联，清理已有导出文件。仅把名字替换为“匿名”但保留账号关联，不属于匿名化。
5. 日常产品中的归档、撤销和作废会保留原记录，**不能**当作已经完成隐私删除。普通 API 的禁止硬删除规则继续保留，隐私处置走受控运维流程，不开放通用删除按钮。
6. 记录处理结果和待备份轮换日期，回复申请人；台账只保存追溯必要信息。灾难恢复时先核对独立保存的请求台账，重新执行快照之后的更正/删除，再对外恢复访问。

## 到期治理

每月由运营负责人检查“活动/培训结束时间 + 2 年”即将到期的记录，并在到期前安排删除或匿名化。活动 `archived`、报名 `cancelled/rejected`、签到 `revoked`、答卷 `void` 都不自动免除期限要求。跨活动账号不随单场到期自动注销；到期活动中的直接身份信息和可追溯关联须一起处置。

当前仓库**没有自动清理业务个人数据的定时任务**；本文确定了人工执行责任与操作流程。本轮未删除任何生产记录。不得在配置后台把业务归档或备份生命周期宣传为“个人信息已自动删除”。安全审计原有至少 1 年要求继续适用，期满及争议保留按最小必要性单独评估。

## 上线配置核对

- 更新生产环境中的 `CC_PARTICIPANT_PRIVACY_NOTICE_VERSION=2026-09-05.v1`；如果没有显式设置则使用新默认值。前后端须一起发布，旧缓存页面提示版本过期时刷新后重试。原有同意记录保留其历史版本，不回填伪造同意。
- 在管理员登录页可用用户名/邮箱密码、邮箱验证码；`/admin/verify-email` 申请/确认验证，`/admin/reset-password` 申请/完成重置。已验证邮箱才可找回，未验证请求仍给统一提示，避免枚举。
- PocketBase Settings 的应用 URL 设为 `https://chatcircle.empact.cn`；配置 SMTP 主机、端口、TLS、发件名称/地址及凭据。只在服务器受控设置中保存凭据。本次迁移把管理员验证/重置邮件链接改到上述页面，token 放 URL fragment 并在页面读取后移除。
- 用运营自有邮箱验收：请求验证 → 点击确认 → 退出 → OTP 登录 → 找回 → 新密码登录 → 旧密码被拒。检查垃圾邮件、失效链接及错误验证码。此测试会发送真实邮件，放在部署完成后的人工验收中。
- 机构发布审核按合作方授权配置；敏感导出默认关闭，有明确使用目的与负责人时再启用。对外只分享活动/问卷公开链接，不能分享管理地址或导出文件。
- 首页页脚检查隐私链接、主体和备案号；政策联系邮箱须有人收件。公安备案如有适用办理要求按实际办理结果补充，不能用 ICP 号代替或编造编号。
- 本机备份与异地备份的凭据、告警、30 天清理及恢复演练按 [异地备份手册](../deploy/offsite-backup.md) 验收。

涉及法定权利与例外的处理以适用法规为准；政策项目参考 [《个人信息保护法》官方文本](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_515a4b20c12f430eab54bb4f56d89f56.html)，不能仅用本手册代替具体事项审查。
