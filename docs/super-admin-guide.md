# 超级管理员后台使用教程

> **这份文档写给谁**：Chat Circles 平台方（Empact）的运营负责人。你不需要懂技术，按页面按钮操作即可完成机构的接入、活动审批、内容发布和全平台数据查看。
>
> **你是机构的工作人员？** 请看另一份：[机构管理员后台使用教程](org-admin-guide.md)。

---

## 〇、30 秒认识这个后台

- 后台登录网址：**`chatcircle.empact.cn/super/login`**（直接输入 `/super` 打不开，必须带上 `/login`）。
- 超管账号**全平台唯一、没有注册入口**，由部署系统时创建。用「用户名或邮箱 + 密码」登录。
- 超管能看到**全平台所有机构**的数据，请格外注意保密。
- 地址栏里另一个你可能见过的 `/_/` 是数据库自带的底层后台，**日常运营用不到**，生产环境也已禁止访问，只有技术人员排障时才会临时使用。本教程不涉及它。

## 一、后台长什么样

登录后左侧菜单共八项：

| 菜单 | 干什么用 |
|---|---|
| **机构与邀请码** | 最常用：接入新机构、给机构发管理员邀请码、调整机构开关、停用机构 |
| **发布审批** | 审批机构提交的活动发布申请 |
| **活动监管** | 查看全平台所有活动，必要时下架 |
| **内容推文** | 发布官网首页可见的推文/文章 |
| **全局看板** | 全平台数据统计 |
| **全局导出** | 导出全平台或指定机构的数据 |
| **全局审计** | 检索全平台的操作记录 |
| **系统与模板** | 查看每日备份状态、维护标准问卷模板 |

用公共电脑操作完请点左下角「**退出登录**」。

## 二、最常见的任务：接入一家新机构

完整流程只有四步：

1. **建机构**：「机构与邀请码」→「**创建机构**」，填机构名称，备注选填（只有平台内部能看到）。
   - 新机构默认：**活动发布直发**（不需要你审批）、**不允许敏感导出**。需要改见下一步。
2. **配开关**（可选）：在该机构行点「**配置开关**」：
   - **活动发布需平台审核**：开启后，这家机构每次发布活动都要你在「发布审批」里批准后才对外可见。
   - **允许机构管理员敏感导出**：开启后，该机构管理员导出数据时可包含姓名、手机号等敏感字段。**这是高危操作，开启前请确认对方确有使用目的和负责人**，详见 [隐私运营手册](privacy-operations.md)。
   - 注意：勾选后**不会立即生效**，页面会弹出后果说明，需要再点「确认变更」——这是故意的防手滑设计。
3. **发邀请码**：在该机构行点「**生成邀请码**」，设置有效期（默认 7 天，最长 90 天），点「生成」。
   - ⚠️ **邀请码明文只显示这一次**！弹出窗口后立刻点「**复制邀请码**」，通过安全渠道（如微信私聊、电话口述）发给机构对接人。关闭窗口后平台也无法再查看，只能重新生成。
   - 邀请码是**一次性**的：一个码只能注册一个管理员账号。机构要加第二个管理员，就再生成一个码。
   - 下方的「管理员邀请码」列表可以看每枚码的状态（未使用/已使用/已撤销/已过期）。码没用了可以「撤销」。
4. **交给对方**：机构对接人拿着邀请码去 `chatcircle.empact.cn/admin/register` 注册，后续操作让对方看 [机构管理员后台使用教程](org-admin-guide.md)。

## 三、审批活动发布申请

只对开启了「发布需平台审核」的机构有这个环节。

1. 「发布审批」页列出所有待审核活动：标题、机构、时间、名额、提交时间。
2. 点「**批准**」→ 确认后活动即刻对外公开：出现在官网「活动广场」列表，也可通过链接/二维码直达。
3. 点「**驳回**」→ **必须填写驳回原因**。机构能看到原因，修改后可重新提交。

批准和驳回都会写入审核历史和审计日志，随时可查。

## 四、活动监管与下架

「活动监管」页可按机构和状态筛选查看全平台所有活动。

- 对「已发布」的活动，操作列有「**下架**」按钮。下架后活动公开入口**立即不可访问**，但报名、签到等历史数据完整保留，可追溯。
- 下架通常用于：活动内容违规、机构要求紧急撤下等情况。下架前建议先与机构电话沟通。

## 五、发布内容推文

「内容推文」页管理的文章会显示在网站公开端（首页、往期活动等位置，文章地址为 `/posts/xxxxx`）。

1. 点「**新建推文**」，填写：
   - **标题**（必填）、摘要（选填）
   - **封面图**：单张图片，不超过 5MB，支持 jpg/png/webp/gif
   - **正文**：Markdown 格式（可以用 `#` 标题、`**加粗**`、列表等简单记号）
   - **外链 URL**（选填）：正文和外链至少填一项
   - 可见性：「可见」则公开端立即展示；「隐藏」则只有后台能看到
2. 行内按钮可以随时「**编辑**」「**置顶 / 取消置顶**」「**隐藏 / 设为可见**」。

> ⚠️ 推文**没有删除按钮**——「隐藏」就是从公开端撤下的方式，操作记录会留审计。

## 六、全局看板与导出

### 6.1 全局看板

「全局看板」按日期、机构、活动状态、角色筛选，指标口径与机构端一致（活动场次、报名数、服务人次、问卷完成率等 8 项）。页面顶部如果出现**备份失败告警横幅**，说明昨日自动备份出了问题，请通知技术人员（备份机制见第七节）。

### 6.2 全局导出

「全局导出」→「新建导出」：选范围（**全平台 / 指定机构 / 单活动**）→ 点「**创建导出**」。

- 勾选「**包含个人信息字段（敏感导出）**」时，会弹出红色二次确认框，点「确认导出个人信息」才会执行。**每次敏感导出都记录在审计日志里**，请确有需要再用。
- 在下方「导出记录」表里点「**下载**」拿文件。每条记录带文件校验值，可用于核对文件没被改动过。
- 超管导出不受机构级"敏感导出开关"限制，因此更要自律：导出文件含参与者个人信息，仅限工作需要，妥善保管、及时清理，合规要求见 [隐私运营手册](privacy-operations.md)。

## 七、系统与模板

### 7.1 备份状态（只读）

「系统与模板」页顶部展示最近一次自动备份的时间和结果。数据库和上传文件**每天自动备份，保留最近 30 天**，无需人工干预，页面上也没有手动备份按钮。看到失败告警请通知技术人员。

### 7.2 标准问卷模板

机构创建活动时勾选的问卷，都来自这里维护的标准模板。

- **新建模板**：填模板代码（大写字母开头，全平台唯一）、名称、描述，并用可视化编辑器添加题目 →「创建模板」。
- **发布新版本**：要改题目时不要新建模板，而是对现有模板「发布新版本」。新版本发布后即不可修改，而且**只影响之后新建的活动问卷**——已创建的活动问卷仍固定在旧版本，不会被动到。
- **停用 / 启用**：停用的模板机构端建活动时选不到，不影响已有问卷。
- 「预览」「版本列表」可查看每个版本的题目和发布记录。

## 八、全局审计

「全局审计」按日期、操作者、机构、动作关键词（如 `export`、`invite`）、结果（成功/失败）检索全平台操作记录。日志不可修改、不可删除。适合排查"这个机构是谁建的""这次敏感导出是谁操作的"等问题。

## 九、常见问题（FAQ）

**Q：机构的邀请码丢了/没复制到怎么办？**
A：明文找不回（库里只存校验值）。直接对该机构重新「生成邀请码」，顺手把旧码撤销。

**Q：机构要求换一个管理员，旧账号怎么处理？**
A：给机构新发一枚邀请码注册新账号即可。目前每个账号独立存在，如需停用旧账号联系技术人员处理。

**Q：能替机构改活动、审报名吗？**
A：超管界面不提供这些操作——活动的日常管理属于机构自己，平台只负责审批、下架等监管动作，职责分离是有意设计。

**Q：机构说"导出不了姓名"？**
A：到「机构与邀请码」确认该机构的「允许敏感导出」开关是否开启。默认是关的，确认对方有合规使用目的后再开。

**Q：停用一个机构会怎样？**
A：该机构所有管理员**立即无法登录后台**，活动数据保留。随时可以再「启用」恢复。

**Q：参与者的平台标准报名字段（比如想加一个"学校"标准字段）能在这里改吗？**
A：界面暂不支持，需联系技术人员通过后台接口处理。

## 十、合规红线（请务必记住）

1. 超管账号全平台唯一、权限最大：**不要外借**，不要设置弱密码，用公共电脑后务必退出登录。
2. 含姓名、手机号的导出文件是平台最敏感的数据，按需导出、最小知悉、用后清理。
3. 参与者提出的查询、更正、删除、注销请求，一律按 [隐私运营手册](privacy-operations.md) 的流程登记处理，不要在后台随手改数据了事。
4. 对外只分享活动和问卷的公开链接，绝不分享后台地址和导出文件。
