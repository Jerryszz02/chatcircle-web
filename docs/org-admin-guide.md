# 机构管理员后台使用教程

> **这份文档写给谁**：各合作机构的工作人员。你不需要懂任何技术，只要能认出页面上的按钮，就能完成从「发布活动」到「导出数据」的全部工作。
>
> **你是超级管理员（平台方）？** 请看另一份：[超级管理员后台使用教程](super-admin-guide.md)。

---

## 〇、30 秒认识这个后台

- 后台网址：**`chatcircle.empact.cn/admin`**（在浏览器地址栏输入，或在网站首页找到管理入口）。
- 你只能看到**本机构**的活动、报名、问卷和数据，看不到别家机构的——这是系统硬性限制，不是出问题了。
- 一个账号同时只能登录一种身份。如果你之前用参与者身份登录过网站，进管理后台前会提示或需要先退出。

## 一、第一次使用：注册与登录

### 1.1 注册账号（只需一次）

1. 向平台超级管理员要一个**一次性邀请码**（一串字母数字，用过即作废，所以不要和别人共用）。
2. 打开 `chatcircle.empact.cn/admin/register`。
3. 依次填写：
   - **邀请码**：原样粘贴
   - **用户名**：4～20 位字母、数字或下划线（大写会自动转小写）
   - **邮箱**：注册后不可修改，找回密码、验证码登录都靠它，请填常用邮箱
   - **密码**：至少 8 位，再确认一遍
4. 点「**注册并登录**」。成功后直接进入后台，邀请码立即失效。

### 1.2 日常登录（两种方式）

- **密码登录**：`chatcircle.empact.cn/admin/login`，输入「用户名或邮箱 + 密码」，点「登录」。
- **邮箱验证码登录**：忘记密码时的快速通道。登录页点「**邮箱验证码登录**」→ 输入邮箱 → 点「发送邮件」→ 把邮件里的验证码填进来 →「验证并登录」。验证码 5 分钟内有效。

### 1.3 忘记密码

登录页点「**忘记密码**」→ 输入邮箱 → 收到邮件后打开里面的链接 → 设置新密码。

> ⚠️ 只有**验证过邮箱**的账号才能用邮件找回密码。建议注册后顺手点后台左下角的「**验证邮箱**」完成验证（收邮件、点链接即可）。没验证也能正常登录使用，只是以后忘密码会更麻烦。

### 1.4 登录不进去？常见原因

| 现象 | 原因与处理 |
|---|---|
| 提示用户名/密码错误 | 用户名不分大小写，但密码分；注意别把参与者账号当成管理员账号 |
| 提示机构已停用 | 你的机构被平台停用了，联系超级管理员 |
| 怎么都收不到邮件 | 先检查垃圾邮件；仍不行联系超级管理员核对邮箱是否填错 |

## 二、后台长什么样

登录后左侧有一条固定菜单，一共五项：

| 菜单 | 干什么用 |
|---|---|
| **活动** | 办活动的主战场：创建、审核报名、签到、问卷、配对都在这里 |
| **培训** | 发布「聆听者培训」，管理培训签到 |
| **看板** | 看本机构的数据统计（活动场次、报名数、签到率、问卷完成率等） |
| **导出** | 把数据导出成 Excel / CSV 文件下载 |
| **审计日志** | 查看本机构后台的操作记录（谁在什么时候做了什么），只读 |

左下角还有「验证邮箱 / 账号安全」和「**退出登录**」。用公共电脑操作完，**记得点退出登录**。

## 三、办一场活动的完整流程（最常用，建议通读）

### 第 1 步：创建活动

「活动」页 → 右上角「**创建活动**」，跟着五步向导走：

1. **基本信息**：活动标题、活动代码（如 `CC_SG_202609_01`，全平台唯一，创建后不能改）、开始/结束时间、地点、总名额、活动介绍。
   - 总名额必须是**正偶数**，系统会自动对半分给「倾诉者」和「聆听者」。
2. **角色与报名**：设置报名开始/结束时间（不填表示不限），勾选「**开放报名**」；下方配置报名表要收集哪些字段。
   - ⚠️ **「姓名」字段务必启用并设为必填**，否则审核和现场都找不到人。
   - 需要额外收集信息（如学校、年级）可点「新增自定义字段」。
3. **现场设置**：填「预计签到开放时间」（**只是给自己看的提示，到点不会自动开放**），以及是否「启用现场配对」（一旦开始配对就不能改了）。
4. **问卷**：勾选要用的问卷模板，为每份问卷设置阶段（活动前/现场/活动后）和预计开放时间（同样**只是提示，实际开放靠手动点按钮**）。
5. **预览与发布**：检查一遍，点「**创建草稿**」。

> 💡 活动创建后**不会出现在任何公开列表**，只能通过你分享的活动链接或二维码访问。所以放心创建，不发布谁也看不到。

### 第 2 步：发布活动

草稿建好后，在活动详情页右上角点按钮发布，分两种情况：

- 按钮是「**直接发布**」→ 点一下，活动即刻对外可访问。
- 按钮是「**提交平台审核**」→ 说明平台要求你机构的活动先过审。提交后等平台超级管理员批准；被驳回的话能看到原因，改完可以重新提交。

发布后，把活动详情页顶部的**公开链接**（形如 `chatcircle.empact.cn/a/xxxxx`）发给参与者，或配合推文宣传。

### 第 3 步：审核报名

活动详情页默认就在「**报名审核**」标签页：

- 新报名出现在「待审核」页签里。点「**报名详情**」可查看报名者填的全部内容。
- 点「**通过**」或「**拒绝**」。通过时还可以顺手调整对方的角色（倾诉者/聆听者），下拉里会显示各角色还剩多少名额；名额满了会提示无法通过。
- 「取消」「回退为通过」等操作必须填写原因，方便日后追溯。

> 🔒 为保护隐私，审核列表默认只显示参与者编号，**不显示姓名**。需要姓名和联系方式时，用「导出」功能导出联系名单，或到现场工作台查看。

### 第 4 步：活动现场

活动当天，打开活动详情页的「**现场工作台**」（数据会自动实时刷新，断线会自动重连）：

1. **开放签到**：点「开放签到」（现场工作台的「快捷动作」里也有），把「签到管理」页里的**固定签到二维码**投到大屏幕或打印出来。参与者用微信/浏览器扫码即可完成签到。
   - 签到成功后系统会自动发**现场编号**（倾诉者 S01、S02…；聆听者 L01、L02…），编号发出去就不会重复利用。
   - 有人扫不了码？到「签到管理」→「**管理员补签**」，选到人、填个原因即可。签错了可以「撤销」（也要填原因，记录会保留）。
2. **开始配对**：签到差不多了，点「**开始配对**」，系统自动把到场的倾诉者和聆听者配成对（组号 P01、P02…）。后来又有人签到，就再点「**再次补齐配对**」。个别配对要调整，用「配对管理」→「手工调整配对」并填写原因。
3. **开放问卷**：到「问卷管理」（或现场工作台快捷动作）找到对应问卷点「**开放填写**」，把问卷二维码投屏；时间到点「**结束填写**」。

### 第 5 步：活动结束后

1. **催问卷**：活动详情页顶部的阶段面板里，每份问卷旁边有「**复制催办文案**」，复制后粘到微信群即可。
2. **看数据/导出**：活动后阶段面板会显示复盘摘要（签到率、各问卷完成情况）；详细数据到「导出」菜单导出。
3. **关闭与归档**：确认不再有人报名/签到，右上角「**关闭活动**」；数据核对无误后「**归档活动**」。归档后活动只读保留，随时还能导出数据。

## 四、其他功能说明

### 4.1 复制活动与机构模板

- 「活动」页右上角「**复制上一场活动**」：把最近一次活动的基本信息、报名表、问卷复制成新草稿，适合系列活动。注意：活动代码、签到二维码、问卷链接都会**重新生成**，历史报名/签到数据**不会**复制过来。
- 活动列表里每场活动有「**另存为机构模板**」，模板行有「**从模板创建活动**」。模板是机构内部复用的"活动底稿"，不能直接发布。

### 4.2 培训（聆听者培训）

「培训」页 →「**创建培训**」，填标题、代码、时间、地点、描述。然后点进培训详情：

1. 右上角「**发布培训**」。
2. 现场点「**开放签到**」，投屏培训签到二维码。
3. 结束后「**关闭培训**」。

两个要点：

- **谁能签到**：只有"报名过任意一场活动的聆听者角色、且报名已通过审核"的账号才扫得进培训。没通过的人会看到提示。
- **培训通过全平台通用**：参与者只要在任何一家机构的培训签到成功过，账号就算"已完成培训"，不用重复参加。

### 4.3 看板

「看板」页可按日期范围、活动状态、角色筛选，显示 8 个指标：活动场次、报名申请数、已通过报名、已拒绝报名、服务人次、去重参与人数、有效答卷数、问卷完成率。下方还有活动明细表，点「管理」直达对应活动。

口径小贴士：

- 「服务人次」按签到次数算（一个人参加 3 场算 3 人次）；「去重参与人数」按账号去重。
- 草稿、待审核、被驳回的活动不计入统计。

### 4.4 导出数据

「导出」页是一个五步向导：**选范围 → 选数据（报名/签到/配对/问卷）→ 行筛选 → 选字段 → 选格式**，最后点「生成预览」确认行数，再「创建导出任务」。稍等片刻即可在下方的「导出记录」里点「**下载**」。

页面上还准备了 7 个现成模板（联系名单、签到名单、现场配对表、活动完整复盘等），点一下自动帮你选好字段。

> ⚠️ **关于敏感字段**（姓名、完整手机号、标记为敏感的报名答案等）：
> - 只有平台超管为你机构开启了「敏感导出」权限，你才能导出这些字段；没开启时预览会直接提示。
> - 含敏感内容的导出需要你勾选"我已知晓"确认框，且每次都会记录在审计日志里。
> - **导出文件包含参与者的个人信息，请只发给工作需要的人，用后妥善保管，不要随手转发到微信群或上传网盘。** 详细合规要求见 [隐私运营手册](privacy-operations.md)。

### 4.5 审计日志

「审计日志」页可以按日期、操作者、动作关键词（如 `export`、`checkin`）检索本机构后台的全部操作记录。日志不可修改、不可删除，至少保留 1 年。适合回答"这条数据是谁删的/改的"这类问题。

## 五、常见问题（FAQ）

**Q：我设置的"预计签到开放时间"到了，签到怎么没自动开？**
A：所有"预计时间"都只是提示。签到、问卷的开放和结束**一律靠手动点按钮**，这是为了防止自动开错时间。

**Q：为什么提示"活动不存在或无权访问"？**
A：大概率是链接属于别家机构的活动。系统只允许看本机构数据，跨机构访问一律显示"不存在"（故意这样设计，不泄露别家信息）。

**Q：活动代码/培训代码能改吗？**
A：不能。代码创建时确定，全平台唯一，用于二维码和链接。

**Q：我想改机构名称、或者关掉"发布需要审核"？**
A：这些属于机构级设置，**只有平台超级管理员能改**。请联系平台方。

**Q：审核报名时为什么看不到报名者姓名？**
A：隐私设计如此。需要姓名请用「导出 → 联系名单」模板，或到现场工作台查看。

**Q：活动不小心关闭了能重开吗？**
A：不能。流程是 草稿 → 已发布 → 已关闭 → 已归档，一路向前不可逆。操作前页面都会有确认提示，看清再点。

**Q：待审核/已下架/已归档状态下右上角没有按钮？**
A：正常。批准、驳回、下架是超级管理员的操作；待审核时只需等结果。

**Q：能在手机上操作后台吗？**
A：可以，浏览器打开 `/admin` 即可，界面做了手机适配。但导出、看板等操作建议用电脑，屏幕大看得清。

## 六、合规红线（请务必记住）

1. 对外只分享**活动公开链接和问卷链接**；不要把后台管理地址（`/admin`）或导出的数据文件发给参与者。
2. 含姓名、手机号的数据导出后妥善保管，仅限工作需要使用，用后及时清理。
3. 参与者提出查询、更正、删除个人信息或注销账号的请求时，不要口头答应，按 [隐私运营手册](privacy-operations.md) 的流程转给平台处理。
